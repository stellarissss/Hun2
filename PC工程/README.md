## 游戏简介

你是一个初到日本的年轻人，身上只有一点启动资金和几个肯跟你混的兄弟。
这座城市不相信眼泪，只认拳头、钞票和地盘。

**你的目标：** 攒钱、招人、买车、抢地盘，在九座城市间闯出名堂，成为真正的老大。

游戏没有固定的通关线，你可以：

- 老老实实打工、跑贸易，当个精明的生意人；
- 或者拉帮结派、火并抢地盘，走一条血路；
- 也可以两边都沾，黑白通吃。

## 安装与启动

### 方式一：安装版（推荐）

1. 运行 `混在日本-4.0.0-x64.exe`；
2. 按提示选择安装目录；
3. 安装完成后，桌面与开始菜单会出现「混在日本」快捷方式；
4. 双击图标即可开始游戏。

### 方式二：便携版

1. 直接双击 `混在日本-便携版-4.0.0.exe`；
2. 无需安装，可放在 U 盘或任意文件夹中运行。

> **提示：** 首次启动会显示短暂的加载画面，属正常现象。

## 操作方式

### 基本操作

| 操作 | 说明 |
| --- | --- |
| 鼠标左键单击 | 点击画面上的按钮、人物、地块进行交互 |
| `Esc` | 关闭当前弹窗 |
| `F11` | 切换全屏 |

### 地图操作

地图（日本全图与城市内部）支持完整的鼠标拖曳与缩放：

| 操作 | 效果 |
| --- | --- |
| **按住左键拖动** | 平移地图。松手后有惯性滑动，快速甩动会顺势滑行一段后平滑停下 |
| **滚轮上滚** | 放大。以鼠标指针所在位置为中心放大，指针指着的地方不会跑掉 |
| **滚轮下滚** | 缩小。缩小到一定程度可看到整张地图全貌 |
| **在画布内双击** | 复位：回到 1.0 倍标准缩放与初始位置 |

缩放范围为 **0.25 倍 ～ 3.0 倍**：

- **0.25 倍**：整张地图尽收眼底，适合规划路线
- **1.0 倍**：默认视角
- **3.0 倍**：放大到能看清城市图标细节

地图右下角会短暂显示当前缩放倍率（如 `1.50x`），操作后自动淡出。

> **小技巧**：想看完整地图，直接向下滚动滚轮；想看清某个城市，把指针移到那个城市上再向上滚。
> 拖曳时不会误触城市按钮，可以放心拖动。

> 游戏为**全鼠标操作**，画面上所有可点击的元素都会有明确的按钮样式。
> 鼠标移到地图上时光标会变为**抓手**形状，按住拖动时变为**抓紧**形状。

## 核心玩法

### 1. 日本地图与城市

游戏舞台覆盖日本 **9 座城市**（含京都、大阪、东京、仙台等）。

- 在**日本地图**界面可以查看各城市位置与状态；
- 点击城市即可**进城**，进入城市街道界面；
- 不同城市有不同特色：有的适合做贸易，有的地盘肥沃，有的工作机会多；
- 跨城市行动会消耗时间，需要规划路线。

**城市内可做的事情：**

- 逛商店、买货卖货
- 找工作、打工赚钱
- 招募兄弟
- 抢占地块、打理产业
- 处理突发事件

---

### 2. 属性与成长

主角与每位兄弟都有一套能力属性：

| 属性 | 作用 |
| --- | --- |
| **生命 (HP)** | 战斗、事件中的耐久，降到 0 会重伤入院 |
| **领导力** | 决定能带多少兄弟、手下是否服你 |
| **体质 / 力量** | 近身格斗的伤害与抗打能力 |
| **枪械** | 使用枪械类武器的命中与伤害 |
| **驾驶** | 飙车、逃逸、车辆战斗的表现 |
| **隐匿** | 潜行、规避警察与敌对势力的能力 |
| **交际** | 谈判、拉人入伙、事件中的说服成功率 |

属性可以通过**打工、战斗、训练、装备**逐步提升。

---

### 3. 现金与混币

游戏中有两套货币：

| 货币 | 用途 | 获取方式 |
| --- | --- | --- |
| **现金** | 日常开销：买车、买货、吃饭、住院 | 打工、贸易、抢地盘、事件奖励 |
| **混币** | 稀有资源，用于高级车辆与特殊道具 | 每日抽奖、成就奖励、剧情事件 |

> **初始资金：** 现金 3,000，混币 20,000。

现金会随游戏进程不断消耗（兄弟工资、日常开销、医疗费等），
需要保持稳定收入，否则容易出现资金链断裂。

---

### 4. 车辆系统

车辆既是代步工具，也是战斗力量。

- 全游戏共 **66 款车型**，分属不同类别：
  普通民用车、豪华车、卡车、警车、高级警车、恐怖分子车、赛车、超级赛车、军用车辆；
- 每辆车有 **速度、载重、安全性** 等参数；
- 载重决定一次能带多少货物，直接影响贸易效率；
- 部分稀有车型只能用**混币**购买。

**车辆用途：**

- 在城市间快速移动
- 运输贸易货物（载重越大赚得越多）
- 追击 / 逃逸 / 车战
- 提升安全性与逃跑成功率

---

### 5. 兄弟与手下

一个人成不了事，你需要招人。

- 全游戏共 **110 位可招募角色**，各有独立属性与特长；
- 招募需要花费现金，部分角色有额外条件；
- 兄弟会**消耗工资**，钱不够会导致士气下降甚至离队；
- 带队人数受**领导力**限制，领导力越高能带的人越多；
- 每个兄弟都可以**装备武器**、**分配任务**。

**用人之道：**

- 战斗型：力量 / 枪械高，适合火并
- 驾驶型：驾驶高，适合飙车与运输
- 交际型：交际高，适合谈判与拉人

---

### 6. 贸易与货物

**低买高卖**是最稳定的赚钱方式。

- 全游戏共 **74 种货物**；
- 每种货物在不同城市的**价格不同**——这正是利润的来源；
- 城市内会显示当前的**热门货物**与行情波动；
- 单次交易量受**车辆载重**限制。

**贸易循环：**

```
在 A 城低价买入 → 开车前往 B 城 → 在 B 城高价卖出 → 赚取差价
```

> **技巧：** 多留意城市间的价差，规划一条「低买高卖」的环线，收益会非常可观。

---

### 7. 工作与赚钱

不想冒险的话，打工也是正经收入。

- 城市中有各类**工作点**，可从事正当或不那么正当的营生；
- 工作有**能力门槛**，属性越高能做的工作越好、报酬越多；
- 打工消耗时间，但风险低；
- 工作还能顺带**提升对应属性**。

**常见收入来源对比：**

| 方式 | 风险 | 收益 | 门槛 |
| --- | --- | --- | --- |
| 打工 | 低 | 稳定但有限 | 低 |
| 贸易 | 中 | 高（看行情） | 需要车与本金 |
| 抢地盘 | 高 | 很高 | 需要人手与战斗力 |
| 随机事件 | 不定 | 波动大 | 无 |

---

### 8. 战斗与火并

当谈判破裂，就只能动手了。

- 战斗为**回合制**，敌我双方轮流行动；
- 可使用**近身攻击**、**枪械射击**、**道具**等；
- 属性（力量 / 枪械 / 体质）直接决定伤害与命中；
- 车辆在部分战斗中也会参与；
- 战败会损失生命、金钱，甚至被送进医院。

**战斗要点：**

- 出手前先看双方属性差，太悬殊不要硬碰；
- 带上装备好的兄弟，人多势众很关键；
- 生命值低时及时撤退，重伤住院会耽误大量时间。

---

### 9. 房产与产业

有了钱，就该置办点家业。

- 可以在城市中购买**房产、车库**等不动产；
- 产业会提供**持续收益**或额外功能（如存放车辆、货物）；
- 地块可以扩张，是长期经营的核心；
- 拥有房产后，部分行动会更方便。

---

### 10. 随机事件

在城市中走动时，会不断触发各种**随机事件**：

- 街头斗殴、兄弟求助、货物交易
- 意外之财、被人勒索、警察盘查
- 有人求你帮忙、老熟人上门
- 车辆抛锚、突发疾病……

每个事件通常有 **2～3 个选项**，不同选择导致不同结果：

- 可能赚到钱、得到货物或招募到人；
- 也可能受伤、破财、树敌。

> **提示：** 事件没有绝对正确的答案，按你当前的资源与目标做选择就好。

---

### 11. 每日抽奖

游戏内置**每日抽奖**系统：

- 每天可以抽一次，随机获得装备 / 道具；
- 抽奖结果会在「马上抽奖」与「试试手气」之间变化；
- 是获取**混币**与稀有装备的重要途径。

## 游戏节奏与建议

### 前期（0 天起）

1. 先用初始资金**打工**积累本金；
2. 买一辆**载重较大的普通车**，为贸易做准备；
3. 招募 1～2 个**能打**的兄弟，保证基本安全。

### 中期

4. 跑**跨城贸易**建立稳定现金流；
5. 逐步**升级车辆**，提高单次运输量；
6. 扩大队伍，开始**抢占地块**；
7. 有条件就买**房产**，增加被动收益。

### 后期

8. 多城市布局，掌控主要贸易路线；
9. 组建强力队伍，挑战更大的地盘；
10. 积累混币，换取**稀有车辆与顶级装备**。

### 通用建议

- **现金为王**：始终留一笔应急钱，用于医疗与工资；
- **不要越级硬拼**：属性差距过大时，先发育；
- **善用地形与城市差异**：不同城市的机会完全不同；
- **事件选择要留后路**：有些选项会带来长期负面影响。

## 更新与升级

游戏会不定期推出更新（新增功能、体验优化、问题修复）。
升级采用**更新包**形式，好处是：

- **不用重装游戏** —— 把更新包放进游戏目录即可
- **不影响存档** —— 更新只替换程序，进度原样保留
- **可跨越版本** —— 不管你现在是哪个版本，直接装最新的即可
- **可随时回退** —— 删除一个文件夹就能退回旧版

### 升级步骤

1. 从 **「更新包版本库」** 中下载最新的更新包
2. **关闭游戏**
3. 解压后双击其中的 **`apply-update.bat`**，按提示操作
   （也可以手动把 `app_overlay` 文件夹复制到游戏安装目录）
4. 启动游戏，即为新版本

### 如何确认更新成功

进入大地图，把鼠标移到地图上：

- 光标变为**抓手**形状 → 更新已生效 ✅
- 滚动滚轮可以**放大缩小**地图 → 更新已生效 ✅

### 想退回旧版？

删除游戏目录下的 `app_overlay` 文件夹即可回到更新前的状态
（`apply-update.bat` 会自动把旧版本备份为 `app_overlay.bak`）。

> 详细的更新包列表与制作规范，见 **「更新包版本库」** 目录下的说明文档。

## 常见问题

**Q：游戏需要联网吗？**
A：不需要。游戏完全离线运行，断网状态下可正常游玩全部内容。

**Q：画面显示不全 / 窗口太小怎么办？**
A：按 `F11` 切换全屏，或拖动窗口边缘调整大小。游戏会自动适配窗口比例。

**Q：没有声音？**
A：请检查系统音量与音频输出设备；游戏背景音乐与音效可在设置中调整。

**Q：游戏卡顿怎么办？**
A：关闭其他占用资源的程序；游戏本身对配置要求不高，一般不会出现明显卡顿。

**Q：进度丢了怎么办？**
A：游戏会自动存档。若遇到异常，请确认存档目录未被清理工具删除。

**Q：可以同时开多个存档吗？**
A：当前版本为单一存档位，新开游戏会覆盖原有进度，请谨慎操作。
