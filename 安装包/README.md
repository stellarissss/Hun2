## 二、合并方法

> 分卷是**纯字节切分**（`split`），不是压缩包，合并即可用，无需解压软件。

### Windows · 命令提示符 CMD（最简单）

```cmd
copy /b 混在日本-4.1.0-x64.part00+混在日本-4.1.0-x64.part01+混在日本-4.1.0-x64.part02+混在日本-4.1.0-x64.part03+混在日本-4.1.0-x64.part04 混在日本-4.1.0-x64.exe
```

### Windows · PowerShell

```powershell
# 安装版
Get-Content .\混在日本-4.1.0-x64.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-4.1.0-x64.exe -Encoding Byte

# 便携版
Get-Content .\混在日本-便携版-4.1.0.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-便携版-4.1.0.exe -Encoding Byte
```

### Linux / macOS

```bash
cat 混在日本-4.1.0-x64.part*      > 混在日本-4.1.0-x64.exe
cat 混在日本-便携版-4.1.0.part*    > 混在日本-便携版-4.1.0.exe
```

### 7-Zip（图形界面）

选中 `*.part00` 右键 → **7-Zip → 提取到当前位置**，会自动串接全部同名分卷。

## 六、操作方式

### 基本操作

- **鼠标左键点击** —— 全部交互（菜单、对话、选项、确认）
- `F11` 切换全屏，`Alt+F4` 退出

### 地图操作（v4.1.0 新增）

| 操作 | 效果 |
|---|---|
| **按住左键拖动** | 平移地图（带惯性滑动） |
| **滚轮上滚** | 放大（以指针位置为锚点） |
| **滚轮下滚** | 缩小，可看到整张地图全貌 |
| **双击画布** | 复位到 1.0 倍 |

缩放范围 **0.25x ～ 3.0x**；鼠标移到地图上时光标变为**抓手**形状。
