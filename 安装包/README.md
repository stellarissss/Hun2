# 安装包分卷说明（Windows x64）

> 本目录存放《混在日本》PC 单机版的 Windows 安装包（**v4.1.1**）。
>
> 由于 GitHub 对单文件有 **100 MB 硬上限**，而安装包约 **107.5 MB**，
> 因此以 **24 MB 分卷** 形式存放。合并后即为可直接运行的 `.exe`。

**推荐用本目录自带的一键工具合并：双击 `合并分卷.bat` 即可。**
（它自动识别所有分卷，不需要手打长命令，升级后仍可继续使用。）

## 二、合并方法

> 分卷是**纯字节切分**（`split`），不是压缩包，合并即可用，无需解压软件。

### 方式一：双击 `合并分卷.bat`（推荐）

把 `合并分卷.bat` 与所有分卷放在同一目录，双击运行。它会自动扫描所有
`.part00` 分卷并逐个合并，版本号变了也不用改脚本。

### 方式二：Windows · 命令提示符 CMD

```cmd
copy /b 混在日本-4.1.1-x64.part00+混在日本-4.1.1-x64.part01+混在日本-4.1.1-x64.part02+混在日本-4.1.1-x64.part03+混在日本-4.1.1-x64.part04 混在日本-4.1.1-x64.exe
```

### 方式三：Windows · PowerShell

```powershell
# 安装版
Get-Content .\混在日本-4.1.1-x64.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-4.1.1-x64.exe -Encoding Byte

# 便携版
Get-Content .\混在日本-便携版-4.1.1.part* -Encoding Byte -ReadCount 0 |
    Set-Content .\混在日本-便携版-4.1.1.exe -Encoding Byte
```

### 方式四：Linux / macOS

```bash
cat 混在日本-4.1.1-x64.part*      > 混在日本-4.1.1-x64.exe
cat 混在日本-便携版-4.1.1.part*    > 混在日本-便携版-4.1.1.exe
```

### 方式五：7-Zip（图形界面）

选中 `*.part00` 右键 → **7-Zip → 提取到当前位置**，会自动串接全部同名分卷。

## 六、操作方式

### 基本操作

- **鼠标左键点击** —— 全部交互（菜单、对话、选项、确认）
- `F11` 切换全屏，`Alt+F4` 退出

### 地图操作

| 操作 | 效果 |
|---|---|
| **按住左键拖动** | 平移地图（带惯性滑动） |
| **滚轮上滚** | 放大（以指针位置为锚点） |
| **滚轮下滚** | 缩小，可看到整张地图全貌 |
| **双击画布** | 复位到 1.0 倍 |

缩放范围 **0.25x ～ 3.0x**；鼠标移到地图上时光标变为**抓手**形状。

## 七、本版本内容

**保留**：完整的「混在日本」核心文字养成玩法、全部城市地图 / 人物 / 车辆 / 商品 / 建筑、
全部随机事件与剧情分支、完整音频音效。初始混币 20000、现金 3000。

**已移除**：内购系统、社团、FC 小游戏、艺妓、黑金小游戏、排行榜、全部联网功能。

**v4.1.0 新增**：地图鼠标拖曳平移（含惯性）、滚轮缩放（0.25x～3.0x）、双击复位、
光标交互反馈、缩放倍率指示。

**v4.1.1 修复**：**修复点击失效问题** —— v4.1.0 中点击判定阈值过小，
真实鼠标按下与抬起之间的轻微位移会被误判为「拖曳」而被吞掉，
导致有时点不动界面。本版已调整判定阈值并重写点击抑制逻辑，点击已完全正常。

> ⚠️ 如果你正在使用 **v4.1.0**，请务必升级到 v4.1.1。

## 八、后续更新

v4.1.0 起，游戏支持**更新包**升级 —— 无需重装、不影响存档、可跨越版本。

更新包统一收录在 **「更新包版本库」** 目录，详见其说明文档。
更新包的安装脚本会自动在全盘 / 全仓库范围内搜索游戏目录，
无论游戏装在哪个盘、哪一层，双击 `apply-update.bat` 即可一键完成。
