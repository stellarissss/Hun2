# 更新包版本库

本目录收录《混在日本》PC 单机版**历次更新的更新包**，供玩家按需取用。

---

## 一、什么是更新包

更新包是一个**可叠加的增量升级包**。它的特点是：

- **无需重装游戏** —— 把更新包放进游戏目录即可完成升级
- **不影响存档** —— 更新只替换程序代码，存档始终安全
- **可叠加任意版本** —— 不管你当前是哪个版本，直接装最新包即可，不用逐版升级
- **可随时回退** —— 删除一个文件夹就能退回更新前的版本

---

## 二、更新包一览

| 版本 | 名称 | 基线要求 | 主要内容 | 包大小 |
|------|------|---------|---------|--------|
| **v4.1.0** | 地图交互增强 | 任意版本（v4.0.0+） | 鼠标拖曳平移、滚轮缩放、双击复位、横屏适配、光标反馈 | 30.1 MB |

> 后续每次更新都会在本表中追加一行，并按 `混在日本-更新包-v<版本>-<名称>/` 的格式新建目录。

## 三、安装方法

### 推荐：一键安装

1. 确认**游戏已关闭**
2. 解压下载的更新包压缩包
3. 双击其中的 **`apply-update.bat`**
4. 按提示确认（脚本会自动寻找游戏目录），等待完成
5. 启动游戏

脚本会：
- 自动定位游戏安装目录
- 检查游戏是否在运行
- 把旧版覆盖层备份为 `app_overlay.bak`（便于回退）
- 把新版本复制到位

### 手动安装

1. 找到游戏安装目录（含 `混在日本.exe` 的那一层）
2. 把更新包内的 **`app_overlay`** 文件夹整个复制进去
3. 完成后目录结构：

```
混在日本/
├── 混在日本.exe
├── resources/
│   ├── app.asar              ← 安装包自带的基础代码（不要动）
│   └── app_overlay/          ← ★ 更新包内容（程序优先加载这里）
│       ├── version.json
│       ├── www/
│       └── electron/
└── app_overlay/              ← （此位置同样有效，便携版推荐）
    └── ...
```

程序会按以下顺序查找更新包，**找到即用**：

1. `<安装目录>/resources/app_overlay/`
2. `<安装目录>/app_overlay/`（与 exe 同级）
3. `%APPDATA%/hun-japan-pc/app_overlay/`

## 四、存档说明

**更新包绝不影响存档。**

存档位置（与程序文件完全分离）：

```
%APPDATA%\hun-japan-pc\saves\
```

游戏内可通过菜单 **「游戏 → 存档目录」** 直接打开。

由于更新包只包含程序代码（`www/` 与 `electron/`），**不包含也不读取**存档文件，
因此无论从哪个版本升级，进度都会原样保留。

---

## 五、回退方法

| 想回到… | 操作 |
|---------|------|
| 上一版（更新前） | 删除 `app_overlay`，把 `app_overlay.bak` 改名为 `app_overlay` |
| 游戏内置初始版本 | 直接删除 `app_overlay` 文件夹 |

---

## 六、如何确认更新已生效

启动游戏 → 进入大地图 → 把鼠标移到地图上：

- 光标变为**抓手**形状 → 交互层已加载 ✅
- 滚动滚轮，地图**放大/缩小**，右下角显示倍率 → 更新已生效 ✅

若均无反应，请检查：
- `app_overlay` 是否放到了正确位置
- 是否多套了一层（错误：`app_overlay/app_overlay/www`；正确：`app_overlay/www`）

## 七、给维护者：如何制作新的更新包

```bash
# 1) 在工程根目录执行
python3 scripts/make_overlay.py \
    --version 4.2.0 \
    --out "dist/update-pkg/混在日本-更新包-v4.2.0-<本次名称>" \
    --notes docs/overlay-notes-v4.2.0.md \
    --zip

# 2) 验证更新包机制（可选但推荐）
bash scripts/verify_overlay.sh

# 3) 把新目录复制进「更新包版本库」，并在上表补一行
```

### 更新包内容规范

| 必须包含 | 说明 |
|---------|------|
| `app_overlay/www/` | 游戏网页层（全部逻辑与资源） |
| `app_overlay/electron/preload.js` | 预加载桥接层 |
| `app_overlay/version.json` | 版本元信息（程序据此显示版本号） |
| `apply-update.bat` | 一键安装脚本 |
| `更新说明.md` | 面向玩家的更新说明 |

| 禁止包含 | 原因 |
|---------|------|
| 任何存档文件 | 会覆盖玩家进度 |
| Electron 运行时（exe / dll） | 属于安装包职责，更新包只更新代码 |
| `node_modules/` | 体积庞大且与运行无关 |

### 版本号规范

采用 `主版本.次版本.修订号`：

- **主版本**：重大玩法或架构调整
- **次版本**：新增功能（如本次的交互增强）
- **修订号**：Bug 修复与小优化

`version.json` 中的 `baseVersion` 默认写 `any`，表示**可叠加安装在任意历史版本之上**。
只有当更新依赖某个前置版本时，才填写具体版本号。
