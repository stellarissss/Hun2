# 《混在日本》PC 单机版 · 更新说明

## v4.1.0 — 地图交互增强版

**发布日期**：2026-09-21
**基线**：可叠加安装在 **任意历史版本** 之上（v4.0.0 及以后）
**存档**：**完全不受影响**，更新后直接继续玩

---

## 一、本次更新解决了什么问题

此前在 PC 上游玩时，地图只能看到局部，且无法移动和缩放：

| 问题 | 表现 |
|------|------|
| 看不到完整地图 | 大地图初始只能看到约 **56% 宽度 × 70% 高度**，边缘城市被裁掉 |
| 无法拖动 | 鼠标按住地图拖动没有任何反应 |
| 无法缩放 | 滚轮无效，地图尺寸固定 |
| 城市点不跟随 | 放大后城市按钮位置与地图贴图错位 |

本次更新将 PC 端地图交互**全面提升**，达到桌面游戏应有的操作体验。

---

## 二、新增功能

### 1. 鼠标拖曳平移

- **按住鼠标左键拖动** 即可左右上下移动地图，地图跟随鼠标移动
- 松手后有**自然惯性滑动**，快速甩动会顺势滑行一段后平滑停止
- 拖出窗口范围松手也能正确结束，不会卡住
- 拖动过程中**不会误触**城市按钮（已做位移阈值判定）

### 2. 滚轮缩放

- **滚轮向上** = 放大，**向下** = 缩小
- **以鼠标指针位置为锚点缩放** —— 指针指着的那个地方会停留在原处，符合直觉
- 缩放范围 **0.25x ～ 3.0x**（最小可看到整张地图，最大可看清细节）
- 缩放后**城市按钮位置自动同步**，点击依然精准

### 3. 双击复位

- **在游戏画布内双击** = 恢复 1.0x 标准缩放并回到初始位置
- 迷路时一键回到常规视角

### 4. 操作光标提示

- 鼠标移到地图上时，光标变为 **抓手** 形态
- 按下拖动时变为 **抓紧** 形态，操作反馈清晰

### 5. 缩放状态指示

- 右下角显示当前缩放倍率（例如 `1.50x`），操作后短暂显示，自动淡出

### 6. 离线安全加固

- 修复了一处原版遗留逻辑：当游戏页面缺少启动参数时，会跳转到外部网站。
  现在改为**就地补全本地默认参数**，离线版**永不访问任何外部站点**。

## 三、操作速查表

| 操作 | 效果 |
|------|------|
| 按住左键拖动 | 平移地图（含惯性） |
| 滚轮上滚 | 放大（以指针为锚点） |
| 滚轮下滚 | 缩小（以指针为锚点） |
| 双击画布 | 复位到 1.0x |
| 单击城市 | 进入城市（不变） |

> **提示**：想看完整地图，滚轮下滚即可；想看清某个城市的细节，把指针移到那里再上滚。

## 四、安装方法

### 方法一：一键安装（推荐）

1. 确认游戏**已关闭**
2. 把更新包解压到任意位置
3. 双击 `apply-update.bat`
4. 按提示确认游戏目录，等待完成
5. 启动游戏即可

### 方法二：手动安装

1. 打开游戏安装目录（里面有 `混在日本.exe` 的那一层）
2. 把更新包里的 **`app_overlay`** 文件夹整个复制进去
3. 完成后目录结构应为：

```
混在日本/                       ← 游戏安装目录
├── 混在日本.exe
├── resources/
│   ├── app.asar                ← 程序自带的基础版本（不动它）
│   └── app_overlay/            ← ★ 更新包内容（程序优先加载这里）
│       ├── version.json
│       ├── www/
│       └── electron/
└── ...
```

4. 启动游戏

## 五、存档说明

**更新不会影响存档。** 原因如下：

- 游戏存档存放在 **用户数据目录**（Windows 上通常为
  `%APPDATA%\hun-japan-pc\saves\`），与程序文件**完全分离**
- 更新包只替换程序代码，**从不包含、也不读取存档**
- 因此无论在哪个版本上安装更新包，都可以直接继续之前的进度

游戏内可通过菜单 **「游戏 → 存档目录」** 直接打开存档所在文件夹
（老版本此菜单位于同一位置）。

## 六、回退方法

如需退回更新前的版本：

1. 关闭游戏
2. 删除游戏目录下的 **`app_overlay`** 文件夹
3. 重新启动游戏 —— 自动回到程序内置版本

`apply-update.bat` 在安装前会自动把旧版本备份为 `app_overlay.bak`，
如需恢复到**上一版**，把 `app_overlay.bak` 改名为 `app_overlay` 即可。

---

## 七、如何确认更新已生效

1. 启动游戏，进入大地图
2. 把鼠标移到地图上 → 光标应变为**抓手**形状
3. 滚动滚轮 → 地图应**放大/缩小**，右下角显示倍率

若以上均无反应，说明更新未生效，请检查：
- `app_overlay` 是否复制到了 `混在日本.exe` **同级目录**
- 是否复制成了 `app_overlay/app_overlay/...`（多套了一层）
